# ราคาน้ำมันไทย + น้ำมันดิบ (GitHub Pages)

เว็บสถิติแบบกราฟหุ้น: เลือกน้ำมันได้ 1–4 ชนิดเพื่อเปรียบเทียบ, มีน้ำมันดิบ Brent/WTI, เปิด/ปิดเหตุการณ์สำคัญได้
ข้อมูลอัปเดตอัตโนมัติด้วย GitHub Actions ทุก 3 ชั่วโมง (ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมี API key)

## โครงสร้าง
- `index.html` หน้าเว็บ (ไฟล์เดียว ไม่ต้อง build)
- `data/prices.json` ข้อมูลราคา (สคริปต์เขียนทับ) — ตอนนี้มีแก๊สโซฮอล์ 95 เป็นข้อมูลตั้งต้น
- `data/events.json` เหตุการณ์สำคัญ แก้ไขเพิ่มเองได้ (`date`, `cat`, `text`; `cat` = pandemic/war/opec/policy/other)
- `scripts/update_prices.py` ดึงราคาจากบางจากและ FRED
- `.github/workflows/update.yml` ตั้งเวลาอัปเดต + deploy

## ตั้งค่าครั้งแรก
1. สร้าง repo บน GitHub แล้ว push ไฟล์ทั้งหมดขึ้น branch `main`
2. Settings → Pages → Source เลือก **GitHub Actions**
3. แท็บ Actions → เลือก workflow "Update prices and deploy" → Run workflow → ติ๊ก **full** (ดึงย้อนหลังทุกปีตั้งแต่ 2017)
4. ดู log ของ step "Fetch prices" ว่าดึงบางจากและ FRED สำเร็จหรือไม่ เสร็จแล้วเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ข้อควรตรวจสอบหลังรันครั้งแรก (สคริปต์ยังไม่เคยรันกับเว็บจริง)
- **การ map คอลัมน์บางจาก:** หัวตารางเป็นรูปภาพ สคริปต์ map ตามตำแหน่ง (ปี 2026 มี 8 คอลัมน์ ตรวจเทียบกับราคาจริงแล้ว) ปีที่จำนวนคอลัมน์ไม่ใช่ 8 จะเก็บเฉพาะแก๊สโซฮอล์ 95 และแจ้งเตือนใน log ถ้าอยากได้ชนิดอื่นในปีเก่า ให้รัน `python scripts/update_prices.py --inspect 2022` ดูลำดับ แล้วเพิ่มใน `COLS_BY_WIDTH`
- **FRED:** ถ้า log ขึ้น "ดึงไม่สำเร็จ" ให้ตรวจ URL/เครือข่าย ราคาน้ำมันดิบจะไม่ขึ้นจนกว่าจะดึงได้
- **Actions ตั้งเวลา:** GitHub อาจหน่วงเวลา cron และอาจปิด workflow ที่ตั้งเวลาไว้ถ้า repo ไม่มีกิจกรรมนาน (โดยเฉพาะ repo สาธารณะ) ถ้าเห็นว่าหยุดอัปเดต ให้เปิด workflow ใหม่ในแท็บ Actions

## หมายเหตุข้อมูล
- ราคาไทยเป็นราคาปลีก กทม. ก่อนภาษีบำรุงท้องถิ่น จากตารางของบางจาก (ราคาแก๊สโซฮอล์ 95 ตรงกับ ปตท. ในวันที่ตรวจเทียบ แต่ไม่ได้ตรวจทุกวัน)
- ราคาน้ำมันดิบเป็น USD/บาร์เรล คนละหน่วยกับราคาปลีก เมื่อเปรียบเทียบข้ามหน่วยเว็บจะแสดงเป็น % การเปลี่ยนแปลงจากต้นช่วงอัตโนมัติ
- ลองบนเครื่อง: `python -m http.server` แล้วเปิด http://localhost:8000
